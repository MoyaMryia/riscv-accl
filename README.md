# riscv-accl

RISC-V inference experiments and reproducible artifacts. Start with the
[current documentation guide](spacemit/DOCS.md) for measured results,
pending experiments, and the next test method. Use the
[SpaceMiT X60 integration](spacemit/README.md) for deployment and reproduction.

`FINAL-REPORT.md`, dated reports, and `lab/` notes describe earlier campaigns.
Their scope and dates matter; they are not the current work queue.

*But above all, try something. The only thing we have to fear is fear itself.*

*然尤要者，在有所试；吾人所畏，惟畏而已。*
