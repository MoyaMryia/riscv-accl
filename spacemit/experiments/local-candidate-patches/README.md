# K1 优化候选冻结补丁

本目录保存 2026-10-08 至 2026-10-12 的候选补丁与来源清单。
补丁字节与原冻结实验记录相同。
`index.json` 保存来源位置、补丁散列和应用检查数量。
本目录不修改生产默认配置。

## 应用关系

除 `combined-dispatch-r2.patch` 外，每个补丁独立应用到原发布源码。
原源码提交为 `a990751d55a4c54acf2bb77d44282c2093652359`。
这些补丁包含所需的已测基础设施修改。
不能先应用其他候选或重复应用基础设施补丁。
源码文件身份必须与对应清单的 `source_sha256` 相同。

`combined-dispatch-r2.patch` 是增量补丁。
它只应用到 `combined-r1.patch` 的结果。
它不能直接应用到原发布源码。
各清单的 `files_sha256` 给出应用后的文件身份。
