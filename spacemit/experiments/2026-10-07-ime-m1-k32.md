# Fixed K32 M1 IME specialization

Status: completed negative operator screen, independently verified. Run `k1-ime-m1-k32-20261007-121231` took 18.11 minutes. Correctness passed; no operator cleared the speed gate. Candidate remains disabled; model/state/useful-answer stages were skipped.

## Motivation and change

The October 7 decode audit attributed 48.61–66.57% of sampled self CPU to
the IME assembly loop labels. Duplicate FFN packing was only 0.024–0.035%
of overlapping audited GEMM worker elapsed and was declined. These shares
do not predict wall-time savings.

This experiment specializes only Q4_0 calls with block length 32, one row,
positive output width and positive K-block count. Each K block executes the
original two load/unpack/int-dot steps directly. The inner-loop counter and
two conditional branches disappear. Load order, pointers, nibble bias,
integer dot order, F16 scale conversion, FP32 scale multiplication and
per-block fused accumulation are preserved. The outer K-block loop and
output tails remain. The default is `SPINE_IME_M1_K32=0`; mode 1 is experimental.
M2/M3, M4, zero points, other block lengths and Q8 retain their original path.
Production graph execution may reduce a multirow tail to an eligible M1 call.

## Sequential gates

1. Three local transformation checks compare the complete expanded assembly
   trace against two original iterations and refuse source drift.
2. 480 raw kernel cases: K32/K64, 1/2/7/64 K blocks, M1/2/3/4/7,
   N=1/15/16/17/32/48, with/without zero points. Require exact candidate versus
   original outputs, scalar M1 Q4_0 and original M4 reference checks where
   supported, processed-row identity and unchanged input/output guards.
3. 104 production graph cases in each preserved-original/control-off/on arm.
   Include Q8 fallback and input/output/scratch guards. Require identical dumps.
   Also compare actual FFN gate/up and down shapes, and all 248,320 output-head
   columns, for both model widths in all three arms.
4. Six alternating-order samples per arm per actual M1 shape and an unchanged
   M32 FFN shape per model: 144 operator measurements. Each measurement is at
   least 100 ms, excludes fixture preparation and checks guards. Each model
   needs at least one M1 gain exceeding both 3% and the control range. No
   clear regression in any shape or original-versus-wrapper control is allowed.
5. Only on operator advancement: 16 full-vocabulary snapshots per model per
   arm, chunks 32/1/31/32, clear/reset and RS=0/3. Require bitwise dump identity.
   RS reference checks do not qualify speculative rollback.
6. Matched cold ABBA control/candidate/candidate/control at 256 prompt tokens
   for each model. Generate 64 tokens with seed 42, temperature 0 and ignore
   EOS; require exact complete prompt, all output tokens and text, zero cache,
   and matching route/attention/M1 activation. Decode gain must exceed both
   3% and observed control range, with no clear prefill regression. Only then
   repeat at 2,048 prompt tokens for both models.

A performance rejection is a measured result, not a technical fault to repair.
If the screen advances, naturally complete useful answers remain a separate
qualification stage using frozen tasks, held-out checks and blind two-order
cloud judgments. Capped throughput never establishes useful-answer speedup.
