# 固定多轮质量验收

日期：2026-10-21，Asia/Singapore。
要求依据：`Requirements.md` 功能完整性第 5 项。
本文件定义题集、判定、入口与记录。
本文件不包含板上运行结果。

## 1 目标

在固定题集上检查多轮推理质量。
每轮回答必须满足题面要求，后续轮次必须保持前面轮次的事实。
两个模型分别运行，每个会话使用独立服务器进程。

## 2 题集

题集定义在 `spacemit/bench/mtp-r3/multi_turn_cases.py`。
共 6 个会话、24 轮，每个会话 4 轮。

| 会话 | 检查内容 |
| --- | --- |
| site_totals | 合计、变更后合计、负责人回忆 |
| inventory | 库存计算、补货判断、修改条件后重算 |
| policy_versions | 旧版与现行规则区分、违规判断、版本号 |
| meeting_gap | 时间空档、延长后冲突、提前后冲突、最早可用时间 |
| duration_math | 单位换算、时长累加、整除节数 |
| doc_citations | 编号对应、合计、反向定位、引用标注 |

首轮给出资料，后续轮次不重复资料。
最后几轮要求回忆首轮事实，用于检查跨轮状态保持。

判定使用确定性正则匹配，不使用模型判分。
每轮列出必须出现的模式与禁止出现的模式。
整数模式带边界，避免把 108 匹配成 1080 的一部分。

## 3 运行配置

| 项 | 值 |
| --- | --- |
| 上下文 | 12288 |
| 单轮输出上限 | 1024 词元 |
| 单轮超时 | 900 s |
| 提示缓存 | 默认关闭 |
| 退化守卫 | 周期 1～3，窗口 3，最短行 20 字符 |
| 每会话服务器 | 独立进程，单槽 |

提示缓存关闭时，每轮重新预填充完整历史。
开启 `--cache-prompt` 时，记录缓存命中词元数，用于单独的缓存复用测量。
两种条件分别记录，不混合汇总。

## 4 通过门槛

全部会话 status 为 passed 时批次通过。
每个会话要求全部轮次完成，且每轮 require 模式全中、forbid 模式全不中。
任一轮不满足时该会话记为 failed，并停止该会话的后续轮次。
任一请求错误、超时、截断、空答或退化重复时该会话记为 incomplete。
批次存在 failed 或 incomplete 会话时，控制器以状态 2 退出。
退出码 2 表示矩阵已执行且保留了失败。

## 5 记录

启动脚本创建任务目录，并写入工具收据。
板上结果目录包含：

| 路径 | 内容 |
| --- | --- |
| `result/cases.json` | 冻结题集副本 |
| `result/protocol.json` | 模型、上下文、输出上限、超时、守卫参数 |
| `result/conversations/<id>/turn-N/` | 请求、回答、逐轮判定 |
| `result/conversations/<id>/result.json` | 会话状态与逐轮指标 |
| `result/progress.json` | 已结算会话数与最后会话 |
| `result/summary.json` | 会话状态、轮次计数、检查计数、门槛 |
| `result/servers/<port>/` | 启动参数、环境、属性、退出状态 |

逐轮记录词元数、墙钟、首词元时延与检查结果。

## 6 失败隔离

一次请求失败只影响它所在的会话。
其余会话继续执行，并按计划结算。
服务器启动失败时该会话记为 incomplete，下一会话重新启动服务器。
批次不重试失败会话；重跑使用新的任务目录。

## 7 命令

生成任务目录：

```bash
bash spacemit/bench/mtp-r3/stage-multi-turn.sh lab/multi-turn-20261021/2b 2B
```

把任务目录复制到板上，在 tmux 中执行：

```bash
cd ~/Projects/riscv-accl-bench-2026-09-27/multi-turn-20261021/2b
bash launch.sh
```

任务目录必须使用新路径。
4B 使用单独目录和 `4B` 参数。
