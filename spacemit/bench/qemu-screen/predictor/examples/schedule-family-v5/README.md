# 固定组合指令模型 V5

本例使用一个固定二进制与固定加载消费算法对。
训练组有 24 个，独立误差校准组有 19 个，保留检查组有 9 个。
训练配置在新二进制中重新测量。
误差界限先于保留组性能测量冻结。

后测方向判断的观测一致性为 9/9。
误差区间的观测覆盖为 7/9。
该结果不能确认声明的 95% 总体覆盖率。
原始误差界限没有根据后测结果调整。

部分小展开函数的数量拟合残差达到约 12%。
不能把这些组合斜率解释为纯硬件延迟。
本例是保留的模型检查记录，不是新算法精度保证。
全部候选均保留。

运行 schedule-demo.py 可以重放冻结模型与原始界限。
结果只适用于固定计划、二进制、输入和 CPU 0 配置。
完整证据见 spacemit/reports/2026-10-12-k1-model-v5.md。
