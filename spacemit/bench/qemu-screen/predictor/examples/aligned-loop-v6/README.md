# 对齐循环直接成本模型 V6

本例使用固定二进制、热输入与 CPU 0。
训练组有 52 个，独立误差校准组有 19 个，保留检查组有 9 个。
旧配置在本次二进制中重新测量。
函数入口与循环入口均按 64 字节对齐。
函数布局使用独立随机种子。

模型分别预测 8、32、128 次展开的实际循环周期。
模型在相同指令组合的已测向量长度之间插值。
每个误差校准组取三个展开版本的最大误差。
误差界限先于保留组性能测量冻结。

后测区间的观测覆盖为 9/9 组和 27/27 个展开版本。
声明的 95% 组覆盖依赖固定范围内配置组的可交换性。
本次观测不能确认总体 95% 覆盖率。
本例不提供新算法或完整算子耗时的置信保证。
V5 的 7/9 覆盖缺口仍保留在独立范例中。
全部候选均保留。

运行 neighbor-demo.py 可以重放冻结模型与原始误差界限。
完整证据见 spacemit/reports/2026-10-12-k1-model-v6.md。
