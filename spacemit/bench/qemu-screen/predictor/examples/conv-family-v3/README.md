# 完整卷积算子范围示例

本例保留同一二进制的动态计数、训练模型和独立误差校准记录。
板端使用 SpacemiT K1 的 CPU 0 至 CPU 3。
频率快照为 1,600,000 kHz。
快照不证明每个测量周期的频率不变。

训练组有 16 个形状。
误差校准组有 19 个形状。
最终检查组有 9 个形状。
模型先于误差校准组测量冻结。
误差界限先于最终检查组测量冻结。

使用标准 Python 运行：

```sh
python3 spacemit/bench/qemu-screen/predictor/family-demo.py --output 新目录
```

结果保留全部候选。
默认区间声明为 95%，并依赖声明范围内形状组的可交换性。
最终检查组的观测覆盖为 9/9。
九个检查组不能确认总体覆盖率恰好等于 95%。
区间较宽，不能确认几个百分点的收益差异。

本例只适用于固定算法对、固定二进制、种子 42 和四个固定核心。
新算法、新二进制、其他线程分布或其他频率必须重新建立范围与误差校准。
本例不使用最终检查组拟合系数。
动态计数不是 K1 耗时。
模型使用完整调用的实测墙钟耗时作为训练目标。
这个目标包含外部调用、等待和摊分后的计数器操作成本。
拟合系数不表示某一硬件部件的因果成本。

完整原始证据见 `spacemit/reports/raw/k1-model-v3-20261012/`。
