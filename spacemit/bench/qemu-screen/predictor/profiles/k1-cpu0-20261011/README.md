# K1 CPU 0 分项参数

这四个文件包含 239 组实际配置。
它们来自 29,736 个通过输出检查的板端周期样本。
全部样本固定在 CPU 0。
已记录的频率快照均为 1,600,000 kHz。
频率快照不能证明每个周期的频率恒定。

| 文件 | 配置数 | 有效样本数 |
| --- | ---: | ---: |
| `components.json` | 189 | 23,436 |
| `ime.json` | 1 | 126 |
| `reductions.json` | 24 | 3,024 |
| `scalar.json` | 25 | 3,150 |

每个参数保留七轮成本拟合、测量范围和循环控制截距。
文件还保存板端二进制、计划、实际库存和样本的 SHA-256。
测量范围不是预测置信区间。
独立指令流成本包含有限寄存器链数的限制。
向量加载测试没有隔离加载结果可用时刻。
固定操作数测试不能证明全部数据分布的时序。

原始证据与限制见 `spacemit/reports/2026-10-11-k1-model-v2.md`。
参数不能直接推广到其他核心、频率、内存配置或 SoC。
