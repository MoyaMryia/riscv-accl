# K1 访存模式参考

本组包含 60 种配置和 420 个有效样本。
配置覆盖 5 种模式、1 或 4 个线程，以及 6 种基础跨度。
每个工作线程使用独立数组。
板端使用 CPU 0 至 CPU 3。
频率快照为 1,600,000 kHz。

数据按墙钟耗时计算架构有效载荷吞吐率。
数据包含循环、栅栏和访问模式成本。
每次测量前重置数组。
较大跨度的测量可能只有一次遍历。
数据不能称为纯内存控制器带宽或实际 DDR 流量。

原周期事件使用通用硬件计数器，其用户态过滤未通过检查。
墙钟吞吐率不依赖该过滤，仍可用于本次固定模式的参考。
重复测量范围不能作为新算法的预测置信区间。

使用 `memory-reference.py` 查询已测配置。
工具拒绝未测配置，并保留全部范围限制。
