# K1 三项短筛选原型

本目录准备隔离代码。
本目录不自动派发板端任务。
本目录不改变生产默认配置。

## 原型

| 原型 | 对照 | 改动 | 待验证边界 |
| --- | --- | --- | --- |
| 卷积免拼接 | 独立的 C1 布局与算术链路 | 直接读取历史状态与当前输入 | 正式计算图、原库对照、别名与完整模型状态 |
| B2 | 原库、同库 B1-r2、同库 B2 | 每线程复制 8 或 16 词元的 K/V 小块 | 全部模型门槛 |
| IME 调度 | 原内核、旧固定 K32 内核 | 交错权重加载与四位数据拆解 | 完整生产形状计时与全部模型门槛 |

IME 原型没有实现跨 K 块双缓冲。
IME 原型不增加向量寄存器。
IME 原型保持点积指令和浮点累加顺序。
旧固定 K32 内核是独立对照，不能把其影响记为新调度收益。

B2 保留 B1-r2 的短历史回退条件。
B2 保留原 F16 位模式。
B2 保持各查询头的数值运算顺序。
小块复制计入计时。

卷积原型测量历史布局转换、输入拼接、卷积和状态写回的总耗时。
候选省去完整输入拼接。
候选仍写回最后三个历史词元。
两臂使用持久的四线程池。
该独立线程池不能代替 GGML 的图调度验证。
该原型暂不支持原位状态别名。
对照把历史转置与输入拼接合成一次复制。
对照没有重建 C1 的全部临时张量。
该原型只能筛选复制与读取机制，不能给出生产链路收益。

## 准备

在仓库根目录执行：

```bash
python3 spacemit/bench/quick-screen/prepare.py \
  lab/local-reference/source-a990751-clean \
  lab/k1-quick-screen-20261011
```

来源必须通过既有固定源码检查。
输出目录必须不存在。
生成目录包含代码、载荷哈希及运行入口。
不得把输出目录放入既有原始记录目录。

可以在本机执行正确性检查：

```bash
python3 spacemit/bench/quick-screen/verify-local.py \
  lab/k1-quick-screen-20261011 \
  lab/k1-quick-screen-local-check-20261011
```

该检查复用已有交叉编译目录。
地址与未定义行为检查在本机运行。
沙箱不支持泄漏检查器使用 ptrace，故该项关闭。
QEMU 仅检查卷积与注意力的数值结果。

## 板端入口

先把整个生成目录复制到板端新目录。
必须在板端 tmux 会话中执行入口。
必须使用已保存的 `expected-provenance.json`。

```bash
bash /path/to/new-payload/run-board.sh \
  /path/to/new-payload \
  /path/to/expected-provenance.json
```

路径占位符必须替换为实际路径。
入口先等待共用锁。
入口持锁构建和运行全部短筛选。
入口取得锁后最多执行 1800 s。
等待锁的时间不计入该预算。
已有 `run` 目录时，入口拒绝执行。
未授权启动时，只准备载荷。

运行器从既有构建记录读取编译和链接参数。
运行器仅在新目录生成对象、库和可执行文件。
运行器核验原库、来源与原对象的前后哈希。
运行器不构建服务器，不加载模型。

## 数值检查

卷积有 60 个用例。
用例包含两条序列、通道尾部、输入步长和 1、2、3、8、31、32 词元。
原型对比完整输出、最后三个状态词元和边界保护。
两臂还必须通过独立标量参考。

B2 有 159 个用例。
用例包含小块尾部、256 与 512 的路径边界、掩码、输入步长和线程回退。
原库、路由控制库及候选库必须产生相同转储。
完整输出和分段状态必须逐位相同。
8 与 16 词元路径都必须有四工作线程日志。

IME 有 480 个原始用例。
用例包含 K32/K64、M1/2/3/4/7、零点和输出尾部。
原实现、旧固定内核和新调度必须逐位相同。
四路生产图各运行 104 个用例。
原库与三路新库的输出转储必须相同。
QEMU 不支持本项目的 IME 指令。
本机汇编输出检查不能代替板端执行。

## 计时与停止条件

每形状执行六个交错块。
每臂每块至少执行 100 ms。
收益必须同时超过 3% 和控制完整变化范围。
明确退化使用同一阈值判定。

卷积的 6144/T32 与 8192/T32 都必须过收益门槛。
T8 形状不得明确退化。
两种 B2 小块分别判定。
各自的 2048/8 与 2048/16 形状都必须过收益门槛。
256 历史形状不得明确退化。
短历史回退不记为小块收益。

IME 测量两个模型的门控投影、下降投影及完整输出头形状。
每个模型至少有一个形状同时胜过原内核与旧固定内核。
所有形状都不得明确退化。
IME 原始计时使用四份分区数据。
该计时不包含量化与生产线程池调度。

数值差异停止对应原型的计时。
构建与夹具故障分别记录。
某个原型失败后，可以继续另一个独立原型。
运行器不自动重试失败版本。
未过门槛的版本不得进入模型实验。
`promising` 只表示短筛选值得继续。
该状态不是最终算子验收。

计时反复使用相同权重。
此协议测量热数据，不测量冷权重性能。
本机或 QEMU 的耗时不得记为 K1 性能。
必须在新目录保存日志、转储及 SHA-256 收据。
不得改写既有原始记录。
