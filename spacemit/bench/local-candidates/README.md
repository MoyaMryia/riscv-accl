# K1 四个隔离候选

日期：2026-10-08。

本目录遵循根目录的 [AGENTS.md](../../../AGENTS.md)。
设计来源见[四个候选设计](../../experiments/2026-10-08-local-candidate-designs.md)。

已实现：A1、B1、C 的组合生成器和四臂控制器、D 的节点配对执行。
已验证：本机和模拟器中的算子正确性、源码变换和编译。
待验证：K1 原库对照、完整模型状态、算子收益、冷请求收益和完整回答。
未实现：须在前一阶段通过后才进入的 A2、B2。
生产默认配置保持不变。

## 文件和入口

| 文件 | 用途 |
| --- | --- |
| `prepare.py` | 校验固定源码，生成各候选、补丁和哈希清单 |
| `attention.h` | A1 的直接点积和 B1 的四头共享内核 |
| `conv-silu.h` | D 的卷积与激活分片执行 |
| `test-attention.cpp` | 注意力正确性、分段对照和短算子计时 |
| `test-conv-silu.cpp` | 配对执行正确性、观察节点回退和短算子计时 |
| `check.py` | 本机编译、交叉编译和模拟器检查 |
| `build-k1.sh` | 校验完整候选源码，并在 K1 构建服务器与计时工具 |
| `test_prepare.py` | 源码校验、补丁往返和实验协议检查 |
| `prefill.py` | C0–C3 的冷请求 ABBA 控制器 |
| `board.py` | 复用固定构建产物，执行隔离编译、原库对照和四候选初筛 |
| `revise-b1.py` | 生成 B1-r2 的短历史线程不足回退版本 |
| `board-b1-r2.py` | 重测 B1-r2，并严格检查各线程的共享与回退边界 |
| `model-c.py` | 复核 C 的必要形状，串行执行状态与冷请求门槛 |
| `repeat-c1.py` | 执行两轮固定的 C1 独立复验，通过后生成原六任务完整回答 |
| `repeat-c.py` | 执行指定 C 臂的两轮独立复验，通过后收集完整回答 |
| `complete_answers.py` | 按实际 C 臂开关收集原六任务的完整回答和路径证据 |

ABBA 的顺序是控制、候选、候选、控制。
RVV 表示 RISC-V 向量扩展。
GQA 表示分组查询注意力。
KV 表示注意力的键和值。
SiLU 表示本设计使用的逐元素激活函数。
RS 表示循环状态回滚配置。

## 生成独立候选

在仓库根目录执行下列命令。
目标目录必须不存在。

```bash
python3 spacemit/bench/local-candidates/prepare.py \
  lab/local-reference/source-a990751-clean \
  lab/k1-A1-ready --candidate A1
```

`--candidate` 接受 `control`、`A1`、`B1`、`C`、`D` 和 `test-bundle`。
`--copy-tree` 生成独立完整源码。
未指定该选项时，生成器只输出变更文件。
`candidate.patch` 包含 route 3 发布补丁和所选候选。
补丁必须应用于固定的干净源码。
不得再次叠加发布补丁。

生成器先核验归档清单中的 3,266 个源文件。
生成器核验发布补丁及其输出哈希。
生成器使用精确替换位置。
校验失败时，生成器停止输出候选。
生成器不改写输入源码。
生成器不覆盖已有目标目录。

`manifest.json` 保存输入哈希、输出哈希、补丁哈希和环境配置。
`test-bundle` 仅供组合编译和正确性检查。
性能实验必须使用对应的独立候选。

板子开机后，可以使用完整源码候选执行下列命令。

```bash
bash spacemit/bench/local-candidates/build-k1.sh \
  lab/k1-A1-ready lab/k1-A1-build
```

该入口要求生成器使用 `--copy-tree`。
该入口复用发布构建的工具链和运行库选项。
`K1_CC`、`K1_CXX`、`K1_SPERT_DIR`、`K1_TCM_DIR` 可指定对应位置。
该板端构建入口尚未执行。

## 候选范围

| 候选 | 开关 | 第一版范围 |
| --- | --- | --- |
| A1 | `SPINE_K1_FA_DECODE=1` | 256 维、单查询、单序列、四线程、VLEN 256、F32 查询、F16 KV |
| B1 | `SPINE_K1_FA_GQA=1` | A1 的形状，并要求四个查询头对应一个 KV 头 |
| C1 | `SPINE_K1_SSM_CONV=3` | 复用已有限定条件的混合卷积 |
| C2 | `SPINE_GDN_PREFILL=1` | 复用已有标量门控循环状态路径 |
| C3 | 上述 C1、C2 开关 | 同一源码同时保留两处修改 |
| D | `SPINE_K1_SSM_CONV=3`，`SPINE_K1_CONV_SILU=1` | 四线程、连续 F32 输出、每序列至少 32 词元、通道数为 64 的倍数 |

A1、B1 排除非零位置偏置、非零分数软上限和注意力汇聚项。
不支持的形状进入原路径。
A1、B1 同时开启时，两个候选均不执行。
只有精确值 `1` 开启新增开关。
未设置或无效值关闭新增开关。
已有卷积开关保留原 `0`、`1`、`2`、`3` 的选择规则。

A1 复制固定版本的分段函数，并只替换点积调用。
A1 保留 Q 转换、指数函数、F16 舍入和跨线程合并。
A2 尚未实现。

B1 在原 KV 区间中复用 K、V 向量加载。
B1 不复制整块 KV。
B1 使用每线程独立、按 64 字节对齐的栈缓冲区。
声明的缓冲区大小为 5,184 字节。
该实现替代设计初稿中的附加工作区方案。
通用规划器和 IME 规划器保持发布版本的相同哈希。
短历史按 KV 头分工，部分线程可能没有查询组。
该分工的 K1 性能待验证。
B2 尚未实现。

D 使用原卷积内核和原 SiLU 辅助函数。
D 保留两个输出张量。
D 只跳过两个节点之间的一次同步。
D 保留单消费者检查。
中间输出标记或额外消费者使 D 回退。
`use_ref` 和全局融合关闭选项使 D 回退。
第一版未覆盖的通道尾部形状进入原路径。
已实现 `--diagnose` 的每线程时间记录。
该记录给出卷积返回到 SiLU 入口的间隔。
该间隔包含节点调度和同步，不等于纯屏障时间。
设置 `SPINE_K1_CONV_SILU_DIAG=1` 时，配对执行关闭。
诊断与性能计时必须分别执行。
K1 诊断结果待验证。

## 本地检查

```bash
python3 spacemit/bench/local-candidates/test_prepare.py
python3 spacemit/bench/local-candidates/check.py \
  lab/k1-candidate-check-new --rvv \
  --reference-lib lab/local-reference/build-a990751-generic/bin
```

检查器使用本地工具链。
检查器不连接板子。
检查器编译各独立候选的变更文件。
检查器为正确性测试构建组合库。
检查器保存对象哈希、库哈希和反汇编。
检查器将本机控制输出与本地干净原库比较。

2026-10-08 的本地检查结果如下。
模拟器配置为 QEMU 11.1.1、RVV、VLEN 256。
交叉编译器为 GCC 16.1.0。
本机编译器为 GCC 11.4.0。

| 检查 | 本机 | 模拟器 |
| --- | --- | --- |
| 注意力输出、部分结果、回退、输入和边界 | 95 个用例通过 | 95 个用例通过 |
| 卷积与 SiLU 输出、观察节点和边界 | 144 个用例通过 | 144 个用例通过 |
| 已有卷积图和历史状态 | 432 个用例通过 | 432 个用例通过 |
| 已有循环状态输出和回退 | 158 个用例通过 | 158 个用例通过 |
| 生成器和协议 | 12 项通过 | 不适用 |

模拟器中已记录 A1、B1、D 和循环状态候选的激活日志。
这些结果不替代 K1 正确性检查。

## 短算子计时入口

编译正确性夹具后，可以执行下列入口。

```bash
./test-attention --bench A1
./test-attention --bench B1
./test-conv-silu --bench
```

每个入口使用六个交错顺序块。
每臂每次累计至少 100 ms。
输入构造和线程池创建位于计时区间外。
开启 `SPINE_K1_TRACE=1` 可以检查实际路径。
计时入口关闭该跟踪开关。
激活检查和性能计时必须分别执行。
板端计时必须持有现有实验共用锁。
本机计时仅用于检查入口，不产生 K1 收益结论。

## C 的模型阶段入口

下列命令只生成协议，不启动模型。

```bash
python3 spacemit/bench/local-candidates/prefill.py \
  lab/k1-C1-plan --candidate C1
```

`--execute` 才启动冷请求比较。
执行还需要 `--server`、`--library`、`--model-2b`、`--model-4b` 和 `--qualification`。
库目录必须同时包含候选的 `libggml-cpu.so` 和 `libllama.so`。
`--lock` 可指定板端共用实验锁。
默认锁与已有卷积实验相同。

资格记录必须包含实际二进制与模型的 `identity`。
记录中的 `numeric_passed`、`state_passed`、`operators_passed` 必须均为 `true`。
`qualified_arms` 必须包含所执行的臂。
这些字段必须来自实际验证。
本目录不生成虚假的通过记录。

C0 关闭两个候选。
C1 只开启卷积候选。
C2 只开启循环状态候选。
C3 同时开启两个候选。
C3 还要求 `--single-results` 提供 C1、C2 的通过结果。
记录中的二进制和模型标识必须一致。

控制器先执行 512 词元输入，再执行 2048 词元输入。
单词元输出阶段比较首词元延迟和预填充时间。
65 词元输出阶段检查解码回归。
每个模型和阶段分别执行 ABBA。
主指标必须超过 3% 和控制的完整波动范围。
任一必要门槛失败时，控制器停止后续阶段。
控制器检查实际激活日志、完整输出词元标识和零缓存复用。
该初筛不能代替完整回答和独立复验。

生成的 `C/test-c-state.cpp` 用于 C1、C2、C3 的完整模型状态检查。
其臂编号分别为 `1`、`2`、`3`。
探针覆盖 `32, 1, 31, 32` 分块、重置和 RS 回退。
该探针必须在板端先于冷请求计时执行。

## 板端后台初筛

2026-10-08 的板端实验使用 `board.py`。
该入口复用已归档基线的编译命令和未修改对象。
该入口在新目录生成候选对象和动态库。
该入口核验模型、基线源码、原库、运行库和候选清单的哈希。
该入口在结束时再次核验基线。

原库、route 3 控制库、A1 和 B1 分别执行注意力探针。
原库、控制库和 C 分别执行卷积图探针。
C 还执行循环状态算子探针。
D 分别执行正确性探针、线程间隔诊断和短算子计时。
算子失败记录保留在对应日志中。
未达门槛的候选不能进入模型阶段。

算子计时使用六个交错块。
收益必须超过 3% 和控制臂的完整变化范围。
初筛还要求所有已测形状没有明确退化。
`eligible_for_model_gates` 只表示初筛结果。
模型阶段必须再按设计复核必要形状和门槛。
该入口不执行完整模型计时。

长任务必须使用板端 tmux。
该入口持有现有实验共用锁。
`summary.json` 和 `phase` 给出阶段状态。
外部启动脚本记录 `exit-status`。
本次会话和定时检查标识见[派发记录](../../reports/raw/k1-local-candidates-20261008-184350/dispatch.json)。

`board.py ROOT D` 只重试 D 的构建、对照和算子阶段。
省略候选参数时，该入口执行四个候选。
该入口等待共用锁，不会与持锁任务同时计时。
`model-c.py ROOT SCREEN_ROOT` 使用已完成初筛的 C 库。
该入口重新核验基线和候选库的哈希。
该入口先执行状态检查，再执行冷请求门槛。
两个单项都通过后，该入口才进入 C3。
该入口在状态检查和冷请求阶段持续持有共用锁。

模型阶段归档必须包含 `spacemit/serve/cached-document-chat.py`。
既有质量检查模块依赖该文件。
控制器先导入检查依赖，再运行模型。
`--reuse-state PREVIOUS_ROOT` 可以复用已完成的状态日志。
控制器复制日志到新目录，并重新核验结果、激活和 RS 回退。
缺少的状态日志仍须通过实际模型探针生成。

混合卷积的请求模式和实际模式分别记录。
请求模式 `3` 在 32 词元且 RS 为 `0` 时选择实际模式 `2`。
其他已声明的回退形状选择实际模式 `0`。
状态控制器按请求模式分组调用既有严格分派检查器。

C1 初筛通过后，独立复验遵循[冻结协议](../../experiments/2026-10-08-local-candidate-repeat-protocol.md)。
`repeat-c1.py ROOT SCREEN_ROOT INITIAL_ROOT` 等待共用锁。
该入口不重新构建候选。
该入口核验初筛的库、模型、服务器和资格收据。
两轮复验均通过后，该入口复用既有六任务完整回答控制器。
生成结束后的状态为 `review-pending`。
必须复核完整文本后才能给出质量结论。

`model-b1.py ROOT OPERATOR_ROOT` 执行 B1-r2 的独立模型初筛。
该入口核验原基线、候选关闭和候选开启的完整词表输出。
状态探针覆盖混合分块、重置、RS 回退和 2048 词元历史。
模型主指标为 2048 词元后的解码时间。
该入口实际切换 GQA 开关，并保存共享路径和短历史回退日志。
协议见 [B1-r2 模型初筛](../../experiments/2026-10-09-local-candidate-B1-r2-model-protocol.md)。
