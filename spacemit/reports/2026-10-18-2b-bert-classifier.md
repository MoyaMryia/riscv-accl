# 2B 路由小型 BERT 分类器微调结果

日期：2026-10-18，Asia/Singapore。

## 结论

本次完成一个 4 层、256 维中文 BERT 的全参数微调，并在 K1 上完成原生推理验证。
固定新测试集的分类命中为 83／96，即 86.458333%。
旧分类器在相同测试集命中 37／96，即 38.541667%。
使用相同新训练数据的线性对照命中 69／96，即 71.875000%。

三个旧代码请求的意图分类从 0／3 改为 3／3。
此计数表示代码意图识别；本次保持 Qwen 权重和回答生成方式不变。
K1 完整分类时间中位数为 78.879218 ms，P95 为 270.697719 ms。
该时间包含原生分词、原生编码的两个 HTTP 请求和分类投影。

BERT 继续提供意图特征，生产入口保持原直接解码配置。
已完成的[固定题集路由回归](2026-10-18-2b-bert-router-results.md)单独报告完整时间和答案质量。

## 2．固定数据

训练集包含 238 条，开发集包含 48 条，测试集包含 96 条。
训练数据来自旧训练集的 78 条与新编的 160 条请求。
旧 `train-code-01` 和 `train-code-20` 因持出任务族重合而排除。
开发集和测试集由独立任务编写过程产生。
分组检查拒绝同一任务族跨拆分，文本检查拒绝归一化重复。

训练前的独立审查修复了明确的跨拆分任务族重合，并补齐资料题所需材料。
这些数据是由隔离任务生成的合成请求，未使用真实业务请求作为训练样本。
测试文件在此过程保持原文；训练与开发任务改用其他任务族。
三个旧 Benchmark 代码输入单独记录为回归集，未进入本次训练。

## 4．K1 原生一致性与时间

板端会话为 `router-bert-bench-20261018-111641-r1`。
批次于 `2026-10-18T11:21:33Z` 正常结束，退出码为 0，原生编码器关闭返回 0。
模型使用 F32 GGUF、CLS 池化、4 线程、256 上下文、batch／ubatch 256，并关闭 Flash Attention。
分类客户端显式请求未归一化的编码向量。

验证输入为 96 道新测试题与 3 道旧回归题，每题执行 3 轮，共 297 次分类。
全部选中 token 序列与 Hugging Face 参考相同，全部类别与 PyTorch 参考相同。
最大 logit 绝对差为 0.006668353905844526，低于预设门禁 0.02。
一致性门禁比较两种实现；分类正确率仍按人工标签分别统计。

| 指标 | BERT 完整分类 | 旧线性函数 |
| --- | ---: | ---: |
| 样本数 | 297 | 297 |
| 最小值 | 52.059366 ms | 2.525280 ms |
| 中位数 | 78.879218 ms | 3.835443 ms |
| P95，nearest-rank | 270.697719 ms | 18.086560 ms |
| 最大值 | 303.901133 ms | 18.924334 ms |

BERT 时间包含分词 HTTP、编码 HTTP、JSON 处理、token 选择和分类投影。
旧线性时间只包含已加载分类器的函数调用。
模型载入、结果写入和参考对照在请求计时之外。
编码器进程 VmHWM 为 83252 KiB；该值单独描述原生编码器进程。

原始转换工具因大小写敏感的 WordPiece 配置而拒绝导出。
本次适配器先核对 BertNormalizer 与 WordPiece 配置，再使用原生 WPM 路径。
它保留大小写选项与词表索引；BPE 或其他 normalizer 配置触发错误。
初始导出错误及适配后的验证记录均保留。
