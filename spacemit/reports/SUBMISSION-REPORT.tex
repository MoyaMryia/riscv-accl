Each slash separates original and final means. "Faster by" is the
original request time divided by the final request time. Both arms use
identical Q4\_0 weights, F16 cache, inputs, and 65 output tokens.
Sections 5 and 5.1 give the complete tables.

Version \nolinkurl{k1-final-20261013-r3} is one build for both models.
It sets the selected parameters in the source. Normal startup requires
no performance flags or experiment variables. The build passes native
checks, state checks, natural code answers, and relocation checks. The
default is the balanced choice of a frozen search. The Scope section at
the end lists the sample counts and the open acceptance items.

\hypertarget{original-baseline-and-compatibility}{%
\section{3. Original baseline and
compatibility}\label{original-baseline-and-compatibility}}

The original source is
\texttt{5ad05d87\allowbreak{}96cb094e\allowbreak{}e23a3a01\allowbreak{}52874f8a\allowbreak{}2b3060f8}
from the SpaceMiT fork. Its K1 build includes an IME2 file and fails.
The first compatibility change removes that single CMake source-list
entry. The resulting build cannot load the current reduced MTP draft
head. The second change loads \nolinkurl{d2t} and uses the stored draft
head width. Neither arm enables the draft decoder.

GPU-default assertion. The r2 delivery fixes that assertion but starts
with four automatic slots. The r3 source fixes the server default to one
slot and receives a fresh complete build. Both failed versions retain
their source, build identities, and logs. No manual performance flag
bypasses these checks.

The previous full-combination regression remains 3.0220477\% for
4B/2048/65 against B1 under its original conditions. The new search does
not erase that failed gate. The IME scalar schedule remains excluded
after its failed performance screen. The final search tests eight
combinations of B1-r2, C1, and C2-r2; none of them enables MTP. The
earlier MTP pilot passes the relative quality gate on both models. Its
six-task total time decreases by 8.63\% on 2B and by 15.22\% on 4B. MTP
stays off because that pilot also applies an absolute usefulness gate.
Direct decode fails the same gate on the interval-code task and on 2B
arithmetic. The

plan} tests MTP again on r3 with the relative quality gate and a
per-category speed gate. GPU offload and page-allocation memory benefits
remain unqualified. Predictor errors and wide intervals remain separate
from measured model results.

  suite on both models with the relative quality gate.

  the 16k and 32k requests use 65 forced output tokens. Release
  condition: run natural long-document answers and long state checks on

  disable one path at a time on the same r3 binary and measure pairs.

  Blocker: the vendor runtime libraries are not in the package. Release
  condition: publish the exact runtime files with their SHA-256 values.
