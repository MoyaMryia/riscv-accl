# K1 性能分析评估基建第一版

日期：2026-10-11，Asia/Singapore。

## 结论与用途

第一版已实现可复用的分析入口、真实代码身份核验、动态轨迹、标定验收和统一报告。
这些接口已通过真实二进制、K1 板测和独立证据核验。
当前周期模型未通过独立验收。
性能估算只能辅助安排板端测量，不能自动淘汰候选。
实际收益门槛保持为 3%。

本轮重点是建立评估流程。
真实原型短测用于检验流程和模型边界。
本轮不修改发布配置，不重启已停止的组合实验，也不把单项收益相加。

## 接口与状态

| 接口 | 已实现内容 | 当前限制 |
| --- | --- | --- |
| `prepare-existing.py` | 固定卷积、IME 与 B2 的既有目标及输入 | 新算子需要增加适配器 |
| `analyze.py coverage` | 实际反汇编、控制流、向量配置传播 | 标量 AVL 表达式尚无静态值证明 |
| `analyze.py trace` | 实际 PC、编码、线程顺序、VL、vtype、掩码和访存地址 | 区域外执行只标记依赖边界 |
| `analyze.py replay` | 字节核验、保守寄存器依赖、逐字节地址 RAW 重叠 | 不证明跨线程内存顺序 |
| MCA 后端 | 使用实际路径指令、操作数与向量配置 | 局部窗口未完成 K1 周期标定 |
| 缓存后端 | 私有一级缓存与共享二级缓存的声明式重放 | 物理地址、同步和缓存时序尚未覆盖 |
| `prepare-calibration.py` | 固定微内核、编译参数、划分协议与目标散列 | 数据范围为合成指令混合 |
| `calibration-analysis.py` | 实际循环提取、稳态斜率、训练拟合与留出集误差 | 不能外推为真实算子或整机精度 |
| `run-board-existing.py` | 冻结载荷、完整数值检查、六区块原型短测 | 目前固定服务三个原型 |
| `analyze.py suite` | 合并身份、覆盖、标定与独立原型板测 | 各测量范围必须分别解释 |
| `verify-evidence.py` | 独立核验文件收据和归档内嵌套收据 | 收据基目录必须显式提供 |

状态区分 `numeric-stop`、`unsupported-instruction`、`fixture-failed`、`model-coverage-insufficient` 和 `needs-board`。
数值差异必须停止候选。
夹具故障不能改记为候选数值失败。
模型覆盖不足不能改记为候选无收益。
输出保留原始命令、目标散列、工具身份、日志、退出状态和 SHA-256 收据。
输出目录必须是新目录。

寄存器依赖区分 RAW、WAR 和 WAW。
RAW 表示读取前一条写入的值。
WAR 表示写入前一条读取的位置。
WAW 表示写入前一条写入的位置。
分析器保留向量寄存器组、掩码、宽化、分段访存和整寄存器操作的依赖范围。
未支持指令与未知状态必须保留为覆盖缺口。

## 真实代码与动态路径

本轮没有用另一套编译器的代码替代既有目标。
动态指令必须逐条匹配目标映像的实际字节。
共享库必须提供实测加载基址。
B2 使用 `-R 4G` 下的来宾加载记录，实际基址为 `0x55d89000`。
每次轨迹重放仍核验完整指令字节。

| 路径 | 动态覆盖 | 数值证据 |
| --- | --- | --- |
| 卷积四种形状 | 32 个完整线程轨迹，共 12,894,656 条指令 | 每种形状的完整输出与状态转储一致 |
| IME 隔离加载 | 每臂 5,504 条指令，覆盖 64 个案例 | 完整输入、向量、指针和保护区检查通过 |
| B2 tile8 | 对照 8 个线程标识，候选 4 个线程标识；每标识上限 30,000 条 | 159 个案例的完整输出与中间区域转储一致 |
| B2 tile16 | 复用已核验对照；候选 4 个线程标识，每标识上限 30,000 条 | 相同 159 个案例的完整转储一致 |

B2 的线程标识包含夹具生命周期中的不同线程。
这些标识不表示同时运行的线程数。
B2 轨迹达到声明上限，不能给出完整函数指令比例。
本轮没有对 B2 执行缓存重放，因为完整线程执行与同步尚未覆盖。

卷积候选的热点指令增加约 16.91% 至 17.02%，记录的写入字节约减半。
这表明候选存在指令数量与访存数量之间的取舍。
仅凭指令数或写入字节不能判断 K1 耗时。
MCA 默认只分析每线程前 1,024 条实际指令。
这些窗口不是完整热点的时间预测。

六个既有热点函数还通过实际共享库的静态配置检查。
当前记录未发现具有多个 SEW／LMUL 状态的向量位置。
该结果不证明 VL 的标量表达式，也不消除调用边界与未知指令的缺口。
IME 点积布局和 X60 写调度仍未完整覆盖。

## 缓存模型的边界

容量使用每核私有 32 KB 一级数据缓存和每簇共享 512 KB 二级缓存。
容量来自 K1 手册。
64 字节缓存行、八路相联、LRU 替换、写回和写分配均为未标定假设。
重放分别采用串行与逐访存回调轮转的声明式交错。
两种交错都不是实测 K1 线程顺序。

地址为来宾虚拟地址。
区域前的缓存状态未知。
预取、TLB、同步、一致性和计算重叠尚未覆盖。
缓存统计不能转换为物理未命中次数、DDR 流量或 K1 周期。
本轮不使用这些统计自动淘汰候选。

## 板端周期标定与独立验收

验收协议在板端能力检查前冻结。
协议散列为 `f19e143cc6ef290592d112e6e514e515b90f3e3159cc42b90b95d0b0bd2ee64b`。
训练集有 6 组，留出集有 5 组和 5 个候选配对。
组名中的 GDN、卷积和注意力表示指令混合类型，不表示真实算子负载。
历史候选结果没有加入独立测试集。

用户态 `perf_event_open` 周期事件可用。
直接执行 `rdcycle` 产生 `SIGILL`，因此后续不使用该方法。
本轮不修改计数器权限。
测量使用 CPU 0，循环长度为 1,000、4,000 和 16,000，每个长度重复 5 次。
16 个实际微内核共得到 240 个有效周期样本。

所有样本的频率快照为 1,600,000 kHz，未记录非自愿上下文切换。
向量结果在事件停止前存储并被校验代码读取。
配对的完整向量输出检查通过。
计数器累计启用时间与运行时间相等，未发现计数器复用。
这些时间字段是同一文件描述符的累计值，不是各样本持续时间。
温度快照为 31,000 至 32,000 毫摄氏度。

周期测量使用全部样本拟合循环次数与周期的斜率。
结果是稳态每循环周期，不是单条指令的固定延迟。
模型只用训练集拟合一个无截距比例参数，结果为 `0.8054451441386492`。
测试集没有参与重新拟合。

| 验收项 | 本次结果 | 固定门槛 | 判定 |
| --- | ---: | ---: | --- |
| 周期绝对相对误差中位数 | 8.8734% | ≤10% | 通过 |
| 周期绝对相对误差最大值 | 13.0372% | ≤20% | 通过 |
| 相对变化误差最大值 | 2.4706 个百分点 | ≤2 个百分点 | 未通过 |
| 配对方向错误 | 0 | 0 | 通过 |
| 候选间排序错误 | 1 | 0 | 未通过 |
| 观测误淘汰风险 | 1 | 0 | 未通过 |

合成卷积配对的实测降幅为 4.4269%，模型降幅为 2.0000%。
若按预测值执行 3% 淘汰，该配对会被错误淘汰。
这证明本轮不能开放自动性能淘汰。
部分有效长度还缺少 MCA 对应参数，因此同时保留模型覆盖不足状态。
观测最大误差不是总体置信区间。

初版机器结果只计数配对方向错误，未统计候选间排序。
该旧结果保留在证据中。
最终结果另外统计全部声明可比较的候选收益配对，得到 1 个排序错误。
该修正没有改变样本，也没有使用测试集重新拟合。

## 真实原型板测对流程的核验

补充协议在本轮原型板测前冻结。
数值检查包括卷积 60 个案例、B2 159 个案例和 IME 64 个案例。
全部检查通过。
B2 原始库与候选库的完整数值转储逐字节一致。
计时还在每个进程内检查完整结果与保护区。

本轮共执行 156 个计时样本，每臂六个区块，交替对照与候选顺序。
每个样本使用最后一个达到 100 ms 的重复段。
卷积四个工作线程分别固定到 CPU 0 至 CPU 3。
B2 的四个工作线程仅可使用 CPU 0 至 CPU 3，但未启用 `strict_cpu`。
IME 局部夹具使用 CPU 0。

频率快照均为 1,600,000 kHz。
温度快照为 33,000 至 40,000 毫摄氏度。
B2 计时对照是同一候选共享库的 tile0 路径，不是原始共享库。
IME 新夹具保留既有两个加载函数的全部指令字节，字节比较通过。
IME 计时还包括函数调用、循环、函数前后代码和完整向量存储。

| 原型与范围 | 候选时间降幅 | 对照极差占比 | 原判据结果 |
| --- | ---: | ---: | --- |
| 卷积 C6144-T32 | 0.6755% | 2.4720% | 未通过 |
| 卷积 C8192-T32 | 1.2821% | 3.8041% | 未通过 |
| 卷积 C6144-T8 | 25.0434% | 18.8948% | 单组通过，波动较大 |
| 卷积 C8192-T8 | 19.0913% | 16.2548% | 单组通过，波动较大 |
| B2 tile8，K2048-H8／H16 | -35.3257%／-33.9402% | 1.4491%／3.3054% | 明确退化 |
| B2 tile16，K2048-H8／H16 | -40.7386%／-38.9827% | 3.1952%／2.6061% | 明确退化 |
| IME 热输入局部加载夹具 | 6.3127% | 2.0145% | 单组通过 |

正降幅表示候选更快，负降幅表示候选更慢。
完整 13 组形状结果见统一报告及原始样本。
卷积两个 T32 形状未通过，因此该原型不满足原多形状进入条件。
B2 两个小块版本均有明确退化。
IME 结果只适用于 2048 字节热输入的局部夹具，完整内核仍待验证。

这些板测不属于合成微内核留出集，也不改变周期模型验收结论。
卷积板测使用另一既有原型夹具，不能把耗时直接对应轨迹夹具的局部 MCA 窗口。
本轮只保留独立测量结论，不据此给出完整模型收益。

## 后续基建范围

已实现：身份、轨迹、保守依赖、声明式缓存、周期数据接口、独立验收、统一报告和证据复核。
已验证：上述真实路径、240 个周期样本、156 个原型计时样本与 32 项单元检查。
待验证：真实算子完整周期误差、部分 VL 时序、IME 点积时序、缓存参数及跨线程同步。

模型未通过时，工具必须继续保留待板端验证状态。
