# BERT 两路代理完整请求回归

## 固定方案

本次把已微调 BERT 接入独立实验代理，完整对照直接解码与 BERT 自动选路。
题集复用[上一轮固定输入](../reports/raw/2b-router-e2e-20261018-r2/cases.json)。
12 道题各执行 baseline、routed 一次，共 24 次回答。
该批用于回归，分类器、题目与选路映射在运行前固定。
生产入口、Qwen 权重和原生二进制保持不变。

| 项目 | 配置 |
| --- | --- |
| 分类器 | 4 层、256 维中文 BERT，选中第 8 轮权重 |
| 编码器 | F32 GGUF，CLS 池化，不归一化，4 线程，256 上下文 |
| 解码后端 | 原 r3，2B dv64k，direct 与纯 prefix MTP |
| 策略 | code 选择 prefix；qa、text、document 选择 direct |
| 分数保护 | 关闭 |
| 解码配置 | 4 线程，batch／ubatch 32，12288 上下文，单 slot，F16 KV |
| 草稿长度、RS、lowacc | 3、0、0 |
| 输出预算 | 4096 token，必须自然结束 |
| 缓存 | cache_prompt=false，逐次核对实际复用数为 0 |
| 请求时限、总预算 | 1800 s、14400 s |

一个外层进程持有共用锁，管理两个解码后端、一个编码器和一个代理。
baseline 直接访问 direct，routed 访问 BERT 代理。
两种请求均保持全部三个原生进程常驻。
按题目序号交替 baseline 优先和 routed 优先。

## 计时与检查

完整时间从客户端开始 HTTP 请求到读完 SSE 的 HTTP 响应边界。
计时包含分词、编码器调用、分类投影、代理转发、预填充与解码。
模型载入、输入 token 核算、答案检查与证据写入单独执行。
routed 响应的 `X-Classifier` 必须为 bert；实际路径头和草稿计数共同检查解码模式。

模型及脚本身份沿用输入 receipt 门禁。
BERT 权重固定为[已验证模型](../reports/2026-10-18-2b-bert-classifier.md)。
三个原生进程分别核对环境和上下文，两个解码后端另核对实际生效配置及 MTP 容量。
网络故障、内部错误、配置不符与传输截断使批次停止并保存记录。
减速、低接受数、输出长度差异和代码功能失败不触发提前停止。
编码器失败返回错误，不自动改用旧分类器或直接解码。

逐题记录完整答案、TTFT、完整时间、分类耗时、输入输出长度、实际选路与逐进程资源。
代码检查和类别速度统计复用[既有回归流程](2026-10-18-2b-router-e2e.md)。
整体质量仍由完整答案审查决定，速度门禁不替代质量判断。
代码功能失败在执行全部请求后使退出码为 2。

## 适用范围

配置：MUSE-Pi-Pro，两个 2B 解码后端和一个 BERT 编码器；全部请求串行执行。
样本：复用 12 个固定输入，代码、中文、问答、长资料各 3 个，共 24 次完整回答。
新请求分布与选路泛化任务由[BERT 报告范围](../reports/2026-10-18-2b-bert-classifier.md#适用范围)统一记录。
