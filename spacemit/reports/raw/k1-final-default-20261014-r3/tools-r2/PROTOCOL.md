# 最终默认配置与真实起始版本对照

本轮依据根目录 `Requirements.md`。
用户选择兼顾两个模型、预填充与解码的均衡目标。
全部测试必须在 tmux 内执行。
板端构建、模型请求和数值检查必须持有固定共用锁。
旧归档与既有原始记录保持字节不变。

## 版本

起始版本为厂商 `5ad05d8796cb094ee23a3a0152874f8a2b3060f8`，不加项目性能补丁。
采用与最终版本相同的 GCC 14、SPERT、TCM 运行库和编译优化设置。
原版 IME1 构建错误地纳入 IME2 文件，首次构建失败。
第一次兼容构建只删除这一个 CMake 源文件列表项。
该构建完成，但无法加载当前模型的缩减草稿词表头。
第二次兼容构建还读取草稿词表映射，并按存储宽度加载草稿输出头。
第二次兼容构建不启用 MTP 草稿解码。
主模型输出头、主计算图、全部计算内核保持原字节。
原始源码、首次构建失败、模型加载失败和两次兼容补丁全部保留。
模型为已锁定 SHA-256 的两个现用 GGUF。
该比较隔离软件版本与默认参数收益，不把历史量化变化计入累计收益。
两个模型的官方来源与全链加工缺口继续保留。

配置搜索使用已核验统一源码与同一次二进制构建。
它包含宽 RISC-V 向量扩展（RVV）注意力、矩阵指令扩展（IME）路由及三个候选。
候选为 C1、C2-r2、B1-r2。
三项共有八种开关组合。
旧组合退化、IME 标量调度失败和真实 TCM 访问限制继续保留。

## 匹配负载

性能搜索使用 512／2048 输入与 65 输出词元。
上下文分配固定为 12288，键和值缓存固定为 F16。
单槽、CPU 后端、直接解码、温度 0、种子 42，禁止提示复用。
冷请求表示复用计数为零，不清理操作系统文件缓存。
输入为固定完整词元列表。

性能请求使用固定单词元偏置，强制两个版本产生相同的 65 词元序列。
这使实际解码历史保持一致，避免不同输出影响后续计算量。
必须核对全部输出词元、文本、有限计时和请求完成状态。
该负载只测性能，不用于评价回答质量。
自然停止回答单独使用无偏置请求。

## 默认配置搜索

第一阶段穷举八种候选组合。
工作线程为 4，批量与微批量为 32。
两个模型、两个输入长度各执行两轮。
第二轮反转第一轮的配置顺序。
本阶段共 64 次冷请求。

第二阶段使用第一阶段选出的候选组合。
搜索线程数 2／4，以及批量和微批量 16／32／64／128。
两个模型与两个输入长度各执行一次，合计 32 次请求。
这是参数初筛，不独立作为稳定收益证明。
若参数改变，则在新参数下重新检查八种候选组合，避免遗漏参数与候选的相互影响。
若新一轮改变候选，则重复一次参数初筛。
最多执行两次候选与参数搜索；两次后仍不稳定则保留完整排序并报告限制。
初筛失败的配置保留失败记录，并排除采用。

均衡分数为四个模型／长度形状中首词元时延比与解码耗时比的几何平均。
各模型、长度与阶段采用相同权重。
分数越小越好。
完整请求耗时同时报告，但不重复计权。
候选必须相对本阶段对照没有明确单项退化。
明确退化门槛为 3% 与对照完整变化范围中的较大值。
处于最低分数 3% 范围内的配置视为本轮无法明确区分。
这类配置优先选择候选数量较少者。
参数初筛在该范围内优先保留四线程与批量 32，再按分数与固定配置顺序选择。

第三阶段独立复验参数选择结果与第二阶段对照。
四个形状分别采用对照、候选、候选、对照顺序。
若参数改变，共 16 次请求。
若参数不变，则使用第一阶段已有的独立两轮数据，不重复相同配置。
复验失败则退回已通过的上一阶段配置，保留失败。
本轮选型称为已测范围内的均衡默认配置，不宣称穷尽所有可能参数。

选定参数还必须通过两个模型的自然代码回答检查。
若改变线程或批量后无法保持旧控制全文，则保留拒绝记录并退回四线程、批量 32。
退回后的同一配置仍必须覆盖两个模型。

## 最终单一构建

选择完成后，生成一份固定默认源码与完整补丁。
将选定内核开关写入源码默认值。
将线程、批量、微批量、注意力方式、上下文和 CPU 配置写入服务器默认值。
重新执行一次完整构建。
正常启动只提供模型与必要依赖位置，不提供优化开关或性能参数。
统一启动器清除继承的实验变量。
最终性能与自然回答必须通过实际无优化参数的默认启动完成。
研究中的手动开关不作为交付默认验证。

## 起始版对最终版

短输入使用 512／2048 输入和 65 输出，每个模型各执行三对交替顺序请求。
长输入使用 8192 输入与 65 输出，每个模型各执行一对。
共 28 次匹配请求。
两臂使用相同权重、精度、输入、输出、上下文和运行库。
起始臂使用带上述兼容处理的原厂源码。
起始臂使用搜索前的四线程、批量 32 公共配置。
最终臂只提供模型、监听端口和模型别名，使用编译默认参数。
分别报告首词元、预填充、解码、请求时长、采样驻留内存和完成状态。
明确区分软件加配置的交付收益与相同参数下的纯内核增量。
长输入只有一对观测，不能证明稳定性或总体置信区间。

自然代码回答使用之前冻结的 Unicode 任务与 106 项检查。
两个模型分别执行起始臂、已核验旧发布控制臂和最终默认臂。
完整文本、自然停止、输出长度与共有错误分别记录。
最终默认不能新增功能检查失败。
最后复制完整二进制到新目录，再用默认入口执行两个模型的本地推理。
保存全部源码、构建、模型、依赖、请求与归档身份。
