## Findings

### P2: matrix output audit accepts missing hashes and differences between arms

`spacemit/bench/verify-results-matrix.py:153–155` checks the uniqueness of
hashes only inside each report row. All missing hashes produce the singleton
set `{None}`, which passes. The check also never compares the RVV-off and
RVV-on rows, although the report claims exact output agreement for them. The
parsed `audit_c` is unused.

We reproduced the problem on temporary copies of the archives, while we
preserved the timing cells:

- We replaced all eight RVV-on short-run token hashes with a different common
  value. The complete 21-row matrix still exited 0 and reported `hash-ok`.
- We replaced all 16 short-run token hashes with null. The matrix still
  exited 0.

Require nonempty hashes, and compare the paired arms that the claim names, before you
validate an `Exact` claim. A single complete arm can establish completion, but
it cannot establish agreement with another arm.

### P2: confidence-interval lookup is not consistently conservative

`spacemit/bench/paired-stats.py:33–39` selects the next larger table key for a
missing integer degree of freedom. For df=11 it returns 2.179, below the
Student t critical value 2.200985. For df=30 it returns 1.960 rather than
2.042272. These choices narrow the stated 95% interval.

The call also floors the fractional Welch degrees of freedom first. That
floor can be very conservative at the current two-launch sample sizes. For the
archived M4 pp128 comparison, df=1.311984, and the precise Student t critical
value is 7.385864. The PR uses 12.706. The PR interval is
[-0.0553, 0.6608] tok/s. The standard Welch interval, under its
independent-arm assumptions, is [0.09465, 0.51089] tok/s. The statement about
whether that interval contains zero therefore depends materially on this
approximation. Two launches per arm are not enough for a robust general
performance recommendation.

Use a precise Student t quantile. Or document and implement a genuinely
conservative bound, instead of a label that calls an inconsistent lookup a
Welch 95% interval.

  archives. This reproduction does not repair the output-audit weakness
  above.

  not implement a K1 prefill speedup. We did not rerun Windows execution and
  fresh model inference during this review.
