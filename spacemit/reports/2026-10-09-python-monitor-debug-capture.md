## 原现场新增线索

解码器按已核验的原 core 与 Python 文件哈希恢复对象字段。
父对象类型为函数，名称为 `__contains__`。
限定名称为 `ItemsView.__contains__`。
父对象偏移 104 的模块字段指向 `collections.abc`。
该字段值为 `0x6a8a28`，故障寄存器参数为 `0x6a0028`。
两值异或为 `0x8a00`，错误参数的类型字段为 `0xc`。

字段解释采用上游 CPython 3.12.3 的布局。
该解释不是完整调试符号恢复。
该不一致不能证明来自硬件，也不能排除先前内存损坏。
恢复记录见[原现场字段审阅](raw/k1-monitor-debug-smoke-20261009-232800/old-core-object-review.json)。

## 新增现场记录

包装器记录原脚本每行的位置、异常及垃圾回收事件。
每次文件读取保留实际字节、SHA-256 和前后文件状态。
隔离夹具可以原子替换有效摘要，模拟读取时摘要发生变化。
夹具不写入旧实验目录。

GDB 在致命信号递交前保存完整现场。
core 保存包含默认筛选可能省略的代码页。
字段断点在原读取指令前后比较内存值与寄存器值。
该断点只覆盖原现场涉及的函数，不能证明其他对象没有损坏。
全部调试模式都会改变时序，因此未复现不能排除历史故障。
